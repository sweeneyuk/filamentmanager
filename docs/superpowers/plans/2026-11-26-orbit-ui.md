# Orbit UI Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every screen of Filament Manager to the approved Orbit design, on desktop and phone, and fix the known client bugs, without changing the server.

**Architecture:** Shared logic moves into pure modules in `client/src/lib/`, shared components into `client/src/ui/`, and each screen is rebuilt in `client/src/screens/<name>/`, replacing its old file in the same task. A mock server and browser tests let every screen be checked without a printer. The app stays usable after every task.

**Tech Stack:** React 19, Vite 8, react-router 7, plain CSS, lucide-react, recharts, socket.io-client, color-namer, `@fontsource-variable/figtree`; `node --test` for logic; Python Playwright with pytest for screens.

**Spec:** `docs/superpowers/specs/2026-11-26-orbit-ui-design.md` (Project doc `claude/2026-11-26-orbit-ui-design.md`). Read it with this plan.
**Mockup:** https://claude.ai/artifact/DTgM5Pd6hP6avhhJ4MJrKs, file `project/Main.dc.html`. Read it before Tasks 3 to 6.
**Code read at:** commit `5817f82`.

## Global Constraints

- Work on branch `orbit-ui`. **Never push to `main`** (it publishes a container image). Ask the owner before the first push.
- Nothing under `server/`, `streamdeck-plugin/` or `.github/` changes.
- Do not change how temperatures are decoded. The owner has confirmed nozzle readings are correct.
- Every current action stays reachable, by keyboard and touch. Nothing is hover only.
- No new features, metrics, searches or filters. No light theme, Tailwind or component kit.
- Keep route paths and `localStorage` keys `token`, `fm_view_mode`, `fm_sort_config`. Media URLs carry `?token=`.
- Colours, radii, type and motion come from the tokens in spec section 6. No hex colours outside `ui/tokens.css`, except filament data and fixtures.
- Inline `style` only for values from data.
- Filament colour always has a `rgba(255,255,255,.28)` outline and is never text colour or the only identifier.
- Targets at least 44 px. 2 px accent focus outline. Respect `prefers-reduced-motion`.
- Widths: 1100 px and up side menu; 768 to 1099 px icon rail; under 768 px bottom bar.
- New class names start `ui-` (shared) or a screen prefix: `ps-`, `sp-`, `hi-`, `ss-`, `an-`, `ca-`, `jo-`, `se-`, `au-`.
- Interface copy: UK spelling, sentence case.
- Screen files over about 300 lines are split.
- Every screen has loading, empty and load-error ("Try again") states.
- Tests never connect to a real printer or server.

## Review Focus

1. Printer data with missing fields (no `raw`, `startTime`, `slicerFilaments`, zero `totalLayerNum` or `remainingTime`): no "NaN" or "undefined" on screen. Test in Task 5.
2. A slot assigned to a spool that is archived or deleted: shows "not assigned" and can still be cleared. Test in Task 6.
3. Damaged `fm_sort_config` or `fm_view_mode` in the browser: Spools opens with defaults (today it crashes on bad JSON). Test in Task 7.
4. Double click on a slow "Add spool": exactly one spool is created. Test in Task 8.
5. Missing amounts or an invalid `currency` setting: money shows in GBP, never an exception. Test in Task 2.

### Task 2: Shared logic

**Files:**
- Create: `client/src/lib/{format,spools,colors,ams,temperature,printState,media}.js` and a `.test.js` beside each except `media.js`

**Interfaces (produces).** Behaviour is moved from the named source unchanged unless stated.

```
format.js      formatMoney(value, currency = 'GBP') -> string      // en-GB; non-finite value → 0; empty or invalid code → GBP
               formatMinutes(min) -> "2h 5m" | "45m"
               currencySymbol(currency = 'GBP') -> "£"            // same fallback as formatMoney
               formatDuration(seconds) -> string                    // Archive.formatDuration
               finishTime(remainingMinutes, now = new Date()) -> "14:05", or "Fri 00:05" when not the same day
spools.js      remainingGrams(spool) -> number >= 0
               remainingFraction(spool) -> 0..1                     // 0 when total_weight is 0 or missing
               lowStockThreshold(settings) -> number                // 200 if unset or not a number
               stockState(spool, threshold) -> 'out' | 'low' | 'ok' // out at <= 0, low below threshold
               filterSpools(spools, filter, threshold)              // 'Active'|'Archived'|'All'|'Used'|'New'|'Low Stock'
               sortSpools(spools, {key, direction})                 // FilamentManager sort
               loadSortConfig(raw) -> {key, direction}              // bad or missing → {key:'id', direction:'desc'}
               loadViewMode(raw) -> 'table' | 'grid'                // default 'table'
               materialTotals(spools) -> [{material, grams}]
               scrapSpools(spools)                                  // 0 < total-used < 100
               restockUrl(spool, settings) -> string | null         // FilamentManager.getBambuProductUrl
               quoteSpoolCost(weightG, quantity, spool) -> number   // weight*quantity*cost/total_weight, else 0
colors.js      colorName(spool) -> string                           // color_name, else color-namer basic, capitalised, else 'Unknown'
               trayHex(trayColor) -> '#rrggbb' | null
ams.js         unitName(settings, printerId, unitId) -> string      // 'External Spool' for 128/254/255, else `AMS ${id+1}`
               slotNumber(unitId, index) -> number                  // 1 for 128/254/255
               trayKey(unitId, index) -> `${unitId}-${index}`
               humidityLabel(unit) -> string | null                 // PrintStatus mapping
               isEmptyHolder(unit, assignments) -> boolean          // id 254 or 255 only, no tray_type, no assignment
               slotView(unit, index, {assignments, spools, state, threshold}) ->
                 {key, number, spool|null, grams, fraction, material, hex, hasAssignment,
                  kind: 'assigned'|'unassigned'|'empty', feeding, inUse, stock}
               spoolLocation(spoolId, {assignments, printers, settings}) -> string | null  // FilamentManager.getAmsLocation
temperature.js nozzleReadings(state) -> [{label, temp, target}]     // PrintStatus.jsx, dual and single
               chamberReading(state) -> {temp, target}
               fanReadings(raw) -> [{label: 'Part'|'Hotend'|'Aux'|'Chamber', percent: number|null}]
printState.js  printPhase(state) -> {id, label, active}             // PREPARE preparing, RUNNING printing, PAUSE paused (active);
                                                                    // FINISH finished, FAILED failed, IDLE/missing idle; else label = status
               predictedTotal(state) -> number | null               // sum of slicerFilaments used_g, null if not > 0
               latestTakeover(state) -> takeover | null             // PrintStatus filter excluding '255'
media.js       mediaUrl(path, token) -> string | null
```

- `showAlert(title, message, isError = false, options)`: error or `options.dialog` → dialog; otherwise toast. `showConfirm` and `showPrompt` keep their signatures.
